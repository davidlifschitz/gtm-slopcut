# SlopCut

Drop source files. Get a copy with long AI comments cut. Files never leave the browser.

Ask this answers: [My coworkers continue to dump hundreds of lines of AI documentation in every PR](https://news.ycombinator.com/item?id=49337050)

- No account
- No upload
- Cap: 8 MB, 20 files
- Keeps license headers, TODOs, and short comments

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```

Heuristic only. Read the preview before you commit.

## GTM

Reply to people who skip the AI comments in review. Copy is in the page footer.
